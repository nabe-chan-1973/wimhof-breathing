# WimHof呼吸法

ウィムホフ呼吸法の実践ガイド。換気 → 息止め → リカバリーを音声で誘導し、
息止め中はヨガニドラのボディスキャンで脱力へ導きます。

**https://nabe-chan-1973.github.io/wimhof-breathing/**

スマホで開いて「ホーム画面に追加」すると、全画面のアプリとして起動します。
一度開けば、以降は電波がなくても動きます。

## ⚠️ 安全のために

- **運転中、入浴中、水の中、水辺では絶対に行わないでください。** 意識を失う可能性があります
- 立ったままではなく、座るか横になって行ってください
- 妊娠中の方、てんかん・心疾患・高血圧のある方は、事前に医師に相談してください
- 我慢大会ではありません。苦しくなったら、いつでも大きく息を吸ってください

このアプリは医療機器ではありません。実践は自己責任で行ってください。

## できること

- ラウンド数 3〜6、ラウンドごとの息止め目標時間を個別に設定
- 換気は 20〜80回、ペース3段階（1呼吸 6.0 / 5.0 / 4.0 秒）
- 息止めは「目標時間で合図して延長」と「自動で次へ」を選択
- 音声ガイドは フル / 合図のみ / なし
- BGM（WebAudio で合成したドローン）、合図音は 実物のティンシャの録音 / シンプル
- 安全装置：息止め中の生存確認の鐘、上限時間での自動リカバリー
- 各ラウンドの息止め時間を記録（端末内にのみ保存。外部へは送信しません）

## 作り

`index.html` 1ファイルで完結しています。音声もアイコン以外の素材もすべて
この中に入っているため、ファイルを1つ持っていればどこでも動きます。

- 進行はすべて実時間から逆算。画面が消えてもカウントがずれません
- BGM は WebAudio によるドローンの合成。音源ファイルを持ちません
- ガイド音声は VOICEVOX で生成した mp3 を data URI として埋め込み
- 合図音は実物のティンシャの録音（`sfx/`）。生存確認の鐘は同じ一打を
  引き伸ばして低くしたもので、目を閉じたまま聞き分けられるようにしている

## ガイド音声を作り直す

セリフの原本は `index.html` の `const L = { ... }` です。

```bash
# VOICEVOX を起動してから
python tools/voicevox.py list                              # 声の一覧
python tools/voicevox.py make --speaker 84 --speed 0.95    # voice/ に41本を生成
python tools/embed_voice.py                                # index.html に埋め込む
```

合図音を差し替えるときは `sfx/` に `tingsha.mp3`（息止め開始・目標到達）、
`tingshaLong.mp3`（終わり）、`bell.mp3`（生存確認）を置いて、同じく
`tools/embed_voice.py` を実行します。`source-*` で始まるファイルは
編集前の原本とみなして埋め込みません。

`--only in,out` で一部だけ作り直せます。`tools/embed_voice.py --clear` で
埋め込みを消すと、端末の音声合成による読み上げに戻ります。

## クレジット

参考にしています。
